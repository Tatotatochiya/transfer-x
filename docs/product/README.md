# Product Documentation

## Purpose

This area answers **what TransferX builds, for whom, and in what order** — at the level of user journeys and priorities, not code. It sits between the business context in [`../business/`](../business/README.md) and the technical implementation in [`../architecture/`](../architecture/README.md) and [`../engineering/`](../engineering/README.md).

## Scope

In scope: personas, user workflows, roadmap/prioritization, and records of significant product decisions.
Out of scope: *why* the business exists (see [`../business/`](../business/README.md)), *how* a workflow is implemented in code (see [`../architecture/`](../architecture/README.md)).
