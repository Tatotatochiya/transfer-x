1b

Sections that fold, and a tab bar on touch screens

On a laptop, only the section you're in stays open. A folded section shows its waiting count, so nothing urgent is hidden. On iPad and phones, the four sections become a bottom tab bar within thumb reach, and each section's pages sit in a chip row under the title. No hamburger.

1c

Top navigation, the same on every device

No sidebar. The four sections are tabs in the top bar, and the current section's pages sit in a second row. Content gets the full 1440px width, which helps tables like the squad list. The same two rows shrink to fit iPad and phone, so there is one model to learn. This replaces the persistent sidebar that RESPONSIVE.md specifies, so it needs that rule changed.
