TransferX · Mobile notifications

Notifications that reach the phone and can be acted on

TransferX is a web app, so phone notifications come through Web Push. On Android this works from Chrome straight away. On iPhone and iPad it only works once TransferX is added to the Home Screen, so the install step is part of the design.
